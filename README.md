# ارتقاء (PWA) - المرحلة 1
## النشر من Windows على GitHub Pages
1. أنشئ مستودعًا عامًا باسم ertiqaa على github.com
2. ارفع كل محتويات الفولدر (Add file > Upload files)
3. Settings > Pages > Branch: main / root > Save
4. افتح الرابط https://USERNAME.github.io/ertiqaa/ من Safari على الـ iPad
5. زر المشاركة > Add to Home Screen
ملاحظة: الأذكار الحالية عينة وحالتها "قيد المراجعة" حتى يتم التحقق من النصوص.
